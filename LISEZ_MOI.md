# ANIMAL ENGLISH ADVENTURE — DOSSIER DE TRANSMISSION

Ce dossier transforme les décisions de conception validées en instructions directement exploitables par Claude Code.

## Démarrer
1. Extraire l'archive dans **un nouveau dossier de projet** ou fusionner prudemment avec un dépôt existant (sauvegarder avant toute fusion).
2. Ouvrir ce dossier dans Claude Code.
3. Copier/coller le texte de `START_CLAUDE_CODE.md` dans la première conversation Claude Code.
4. Vérifier que Claude a lu `CLAUDE.md` et les fichiers de `docs/`.
5. Le faire travailler dans le dépôt, lancer le programme et tester les fonctionnalités, plutôt que de se contenter de descriptions.

## Fichiers
- `CLAUDE.md` — règles permanentes à respecter par Claude Code.
- `START_CLAUDE_CODE.md` — première commande prête à envoyer.
- `docs/CAHIER_DES_CHARGES.md` — produit, liberté de jeu, géographie, contenus.
- `docs/PROGRESSION_PEDAGOGIQUE.md` — programme complet en 24 domaines et mode d'évaluation.
- `docs/MOTEUR_DE_MISSIONS.md` — composition de quêtes contextualisées et anti-répétition.
- `docs/FAMILLES_ET_CROISSANCE.md` — parents, bébés, croissance, souvenirs.
- `docs/DIRECTION_ARTISTIQUE.md` — charte visuelle et instructions de transfert des images.
- `docs/CRITERES_ACCEPTATION.md` — plan de développement et tests.
- `data/biomes.json`, `data/species.json`, `data/quest_archetypes.json`, `data/quest_examples.json` — jeux de données de départ.
- `assets/references/` — mettre ici les images que vous avez aimées, conservées comme références stylistiques.
- `assets/originals/` — mettre ici les assets originaux créés et autorisés pour le jeu.

## Important pour les images
Les images illustratives apparues dans la conversation peuvent provenir de recherches visuelles ; elles ne sont pas nécessairement des images originales dont les droits de réutilisation sont acquis. Voir `docs/DIRECTION_ARTISTIQUE.md` avant toute intégration. Le paquet **ne contient pas** ces images : les enregistrer séparément dans `assets/references/`.

## Périmètre
Le dossier spécifie un objectif produit complet. Il n'affirme pas que la totalité des graphismes, animations, personnages, voix et 24 modules sont déjà produits. Une réalisation incrémentale avec validation est nécessaire.
